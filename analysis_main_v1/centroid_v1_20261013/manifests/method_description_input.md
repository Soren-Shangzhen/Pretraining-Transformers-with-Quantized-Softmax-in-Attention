# 格内质量守恒重构规则（Centroid）：方法描述

日期：2026-09-30 · 性质：方法描述，不含实验计划与评估结论

---

## 1. 设定

单行、单 head，可见 token j = 1..n。z_j = s_j − rowmax（或按现有算子的行锚定方式），w_j = exp(z_j)，Z = Σ_j w_j。逐行校准把 z 的取值范围切成 K 个区间，token j 落入格 b(j)，格 b 的成员数记为 |b|。分格规则与现有算子相同，本方法只改变每个格的代表权重。

---

## 2. 三层质量守恒

| 层级 | 含义 | 现有算子 |
|---|---|---|
| 全局 | Σ_j p̂_j = 1 | 满足：分母取量化权重之和 |
| 格内 | 对每个格 b：Σ_{j∈b} ŵ_j = Σ_{j∈b} w_j | 不满足 |
| 逐 token | ŵ_j = w_j | 精确 softmax |

本方法满足前两层。

---

## 3. 重构规则

### 3.1 定义

对每个格 b，代表权重取格内 exp 的算术均值：

    w*_b = (1/|b|) · Σ_{j∈b} exp(z_j) = exp( log-mean-exp_{j∈b}(z_j) )

格内每个 token 的量化权重为 ŵ_j = w*_{b(j)}。输出：

    ô = Σ_b w*_b · Σ_{j∈b} v_j  /  Σ_b |b| · w*_b

分母恒等于 Z，因此 p̂_j = ŵ_j / Z，且 Σ_{j∈b} p̂_j = Σ_{j∈b} p_j 对每个格成立。

### 3.2 近似版本（Centroid-2）

格内只保存三个累加器：计数 |b|、Σ_{j∈b} z_j、Σ_{j∈b} z_j²。令 z̄_b、σ²_b 为格内均值与方差，取

    w*_b ≈ exp( z̄_b + σ²_b / 2 )

这是 log-mean-exp 在格内分布为高斯时的精确值，其他分布下为近似。每行需要 K 次 exp。

### 3.3 与现有两条规则的对照

| 规则 | 代表权重 | 格内质量 | 离散化误差结构 | 梯度 |
|---|---|---|---|---|
| Nearest | exp(格中心) | 不保证 | 符号随 token 在格内位置交替 | 格内为零，使用 LERP 作为 surrogate |
| LERP | 权重域弦插值，逐 token 连续 | 不保证 | 单侧为正 | 分段线性，格内非零 |
| Centroid | (1/\|b\|)·Σ_{j∈b} exp(z_j) | 精确 | 格内零均值 | ∂w*_b/∂z_j = exp(z_j)/\|b\|，前后向一致 |
| Centroid-2 | exp(z̄_b + σ²_b/2) | 近似 | 格内近似零均值 | 对 z̄_b、σ²_b 链式求导，前后向一致 |

---

## 4. 性质

- **MSE 最优性**：给定分格，格内算术均值是权重域平方误差最小的代表值（Lloyd 中心条件）。
- **格中心与格内均值之差**：格内分布近似均匀时，log-mean-exp 与格中心之差约为 h²/24，h 为格宽（单位 nat）。格内分布偏斜时该差值不受此界约束。
- **梯度**：Centroid 的梯度对格内每个 token 非零，权重为该 token 在格内 exp 之和中的份额；不需要 straight-through 估计。
- **不连续性**：分格边界由逐行校准统计决定，token 跨格时相关两格的 w*_b 同时改变，输出不连续；这与现有算子相同。
- **扫描次数**：与现有算子相同，两遍：第一遍确定分格，第二遍累加与重构。

## 5. 计算与存储

| 项目 | 现有 Nearest / LERP | Centroid | Centroid-2 |
|---|---|---|---|
| 每 token exp | 0 | 1 | 0 |
| 每行 exp | 0（查表）| 0 | K |
| 每 token 其他 | 比较、索引 | 比较、索引、1 次加 | 比较、索引、2 次加、1 次乘 |
| 每行额外状态 | 校准统计 | K 个浮点（码本） | 3K 个累加器 |
| P 的索引位宽 | ⌈log₂(K+1)⌉ | ⌈log₂(K+1)⌉，外加每行 K 个浮点码本 | 同左 |
| PV | 逐 token n·d MAC，或按格累加后 K·d 次乘 | 按格累加 Σ_{j∈b} v_j（n·d 次加）后 K·d 次乘 | 同左 |

精确 Centroid 不减少 exp 次数；Centroid-2 将每行 exp 次数从 n 降为 K。

## 6. 相关已有内容

| 工作 | 内容 | 与本方法的关系 |
|---|---|---|
| Lloyd / Lloyd-Max | 给定分格，MSE 最优代表值为格内均值 | 本方法的代表值规则即此条件 |
| MXAttention（arXiv 2607.24377），Pre-Normalization Quantization | 用同一份量化 exp tile 更新行和与输出，使概率按构造归一 | 属于全局层质量守恒；本方法在此之上增加格内层 |
| Qiu & Yao；Attn-QAT（arXiv 2603.00040） | 低精度 P 的 backward 一致性与 δ 一致性 | 处理的是量化 P 与梯度计算之间的精度匹配；本方法的梯度一致性来自代表值对成员可微 |
| Softermax（DAC 2021）、ConSmax | 静态分段的 exp 近似；去除 row reduction | 分格静态或无分格，不涉及代表值的格内统计 |
| 训练侧论文 LERP / Nearest | 逐行自适应分格下的两条重构规则 | 本方法为同一分格下的第三条重构规则 |

未核实：MXAttention 全文；attention 训练中使用格内均值重构的直接先例（本轮一次检索未见，未穷尽）。
